Manual de desarrollo de aplicaciones móviles
Este manual explica cómo se construyen las aplicaciones móviles a la medida que NovaTech entrega a sus clientes. Se usa un framework multiplataforma para compartir el código entre Android e iOS. El proyecto se organiza por módulos de funcionalidad, con una capa de datos que consume las APIs del cliente y una capa de presentación desacoplada. Se definen pruebas de interfaz en dispositivos reales y emuladores. Para publicar en las tiendas de aplicaciones, el equipo prepara certificados, íconos, capturas y descripciones, y cumple los lineamientos de cada plataforma. Las actualizaciones se publican por etapas para detectar errores con pocos usuarios.
