Guía de documentación de la API de facturación
La API REST de facturación electrónica permite a los clientes emitir, consultar y cancelar comprobantes CFDI desde sus propios sistemas. Cada endpoint se describe en la especificación OpenAPI con sus parámetros, ejemplos de petición y respuesta y códigos de error. La autenticación se realiza con tokens que expiran cada hora y se renuevan con un token de actualización. Las peticiones están limitadas por minuto para proteger la plataforma. Los cambios que rompen compatibilidad se publican en una nueva versión del servicio y se anuncian con noventa días de anticipación. El portal de desarrolladores incluye un entorno de pruebas con datos ficticios para integrar sin riesgo.
