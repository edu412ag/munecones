Estándar de código para JavaScript y TypeScript en el frontend
Las aplicaciones web y móviles de NovaTech se escriben en TypeScript con el framework de componentes acordado por el equipo. Se utiliza ESLint y Prettier para uniformar el estilo y evitar errores comunes antes de abrir una solicitud de cambio. Los componentes deben ser pequeños, reutilizables y probados con pruebas de interfaz. Se evita el uso de tipos genéricos sin justificación y se documentan las propiedades públicas. El estado compartido se maneja con una única librería definida por la arquitectura. Cada pull request incluye capturas de la interfaz cuando modifica pantallas visibles al usuario y debe cumplir las reglas de accesibilidad.
