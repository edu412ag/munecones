Estándar de código en Python
Todo el código Python de NovaTech sigue la guía PEP 8 y se valida automáticamente con un linter en cada commit. Los nombres de funciones y variables usan minúsculas con guiones bajos y las clases emplean mayúsculas iniciales. Cada módulo incluye docstrings que describen su propósito, parámetros y valores de retorno. Se prohíbe dejar código comentado y se recomienda escribir funciones cortas con una sola responsabilidad. Los cambios llegan al repositorio mediante pull requests que deben ser revisados por al menos un compañero antes de integrarse a la rama principal. Las dependencias se fijan por versión en el archivo de requerimientos.
